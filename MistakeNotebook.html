How do I get a Client ID?
  1. Go to console.cloud.google.com and create a project.
  2. Enable the Google Drive API for it.
  3. Configure the OAuth consent screen (External, add yourself as a test user).
  4. Create an OAuth Client ID of type "Web application".
  5. Add the exact URL where this page is hosted under "Authorized JavaScript origins".
  6. Paste the generated Client ID above.

Tip: this ID isn't secret — edit the DEFAULT_CLIENT_ID constant near the top of the file's script and re-upload it. Every device that opens this page will then go straight to a "Sign in with Google" button — nothing to paste, ever, on any device.
